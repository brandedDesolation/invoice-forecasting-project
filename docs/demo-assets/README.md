# Demo Invoice Assets

These files are safe, synthetic invoice samples for capstone preparation.

Recommended usage:
- Use `simple-service-invoice.txt` as the clean English reference invoice when explaining expected fields.
- Use `turkish-style-invoice.txt` as the Turkish-style reference invoice when explaining local invoice terminology.
- For live OCR upload, convert either text file to PDF from your editor or browser print dialog, then upload the PDF through `/admin/invoices/upload`.

The seeded database already includes matching demo invoices, so the live demo can still continue even if OCR quality varies.
